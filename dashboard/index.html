    How the radar works

    Every protocol in the snapshot that records no token is priced from the snapshot’s own figures. The category’s ratio is the median market-cap-to-TVL of the protocols in that category that already trade, shrunk toward the whole snapshot’s median when the category has few live peers. Base value is TVL times that ratio. Growth is the seven-day TVL change, clamped to −60%..+120%, and moves the value by half its size. Maturity rises with the days a protocol has run with no token, from 0.6 to 1.0 over three years. Running on more chains adds 5% a chain, up to four extra chains. Nothing here is a prediction that a token launches, or when: the implied value is this entry’s own claim about what a launch would be worth if the record stayed as it is.
